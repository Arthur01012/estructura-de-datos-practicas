Estructura de Datos — Prácticas y Ejercicios (E-ETD-2)

Repositorio destinado al desarrollo de prácticas de laboratorio, ejercicios y objetos de aprendizaje de la asignatura "Estructura de Datos".

---

=== 🛠️ Requisitos del Entorno ===

-Lenguaje: Java Standard Edition (JDK 21 LTS recomendado)
-IDE: Apache NetBeans (v17 o superior)
-Herramienta de compilación: Ant
-Codificación del proyecto: UTF-8

---

=== 📁 Estructura del Proyecto ===

El código fuente se encuentra organizado por unidades temáticas dentro del paquete base `com.uthh.edd`:

```text
src/
└── com/uthh/edd/
    ├── unidad1/
    │   ├── tda/            # Tipos de Datos Abstractos
    │   ├── recursion/      # Métodos y algoritmos recursivos
    │   ├── arreglos/       # Manipulación y operaciones con arreglos
    │   └── genericos/      # Tipos genéricos y parametrizados
    │
    ├── unidad2/
    │   ├── listas/         # Listas enlazadas (simples, dobles, circulares)
    │   ├── pilas/          # Estructuras LIFO (Stack)
    │   ├── colas/          # Estructuras FIFO (Queue, Deque, Prioridad)
    │   └── ordenamiento/   # Algoritmos de ordenamiento
    │
    └── unidad3/
        ├── arboles/        # Árboles binarios y balanceados (BST, AVL)
        ├── diccionarios/   # Tablas hash y mapeos
        └── conjuntos/      # Colecciones de conjuntos (Sets)
